How to publish
  1. Click Download updated catalog-new.js.
  2. On GitHub, open the repository, click Add file → Upload files, drop the file in, and commit. It replaces the old one.
  3. Open sw.js on GitHub, click the pencil, change the date at the end of the VERSION line (any new text works), and commit, so phones pick up the change.
